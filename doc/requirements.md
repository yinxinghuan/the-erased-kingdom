# 《被删去的王国》需求文档

## 1. Overview

《被删去的王国 / The Erased Kingdom》是一款影像优先的开放世界 AI 角色扮演游戏：玩家作为未被登记的边境信使，携带能暂时恢复真实事物的空白王印，自由探索四个正在消失的区域、维持伙伴与物资、经历危险和战斗，最终决定谁有权书写这个王国；其他玩家留下的限时批注、物资和公共修复会影响旅程，但不是理解或完成主线的前提。

单次游玩建议 8–15 分钟；完整主线约 `80–120` 个有效决策、`4–7` 小时，可跨多次存档继续；完成全部地区、伙伴和页边支线约 `8–12` 小时。主线没有固定回合数，章节由见证页、地点、关系和已兑现的承诺推进。

Game profile：单次打开以完成一个地标、见证或人物承诺为自然停止点；跨次保留地点恢复、人物登场、队伍、关系、背包、数值、见证页、危险与结局能力。首个有效动作是苹果谷三选一抢救，首局目标是写回一个安全地标，前 10 分钟建立“证据才能写回、一次只能承诺一处”的规则；长期回访理由是探索不同地区、推进伙伴关系并组成自己的大修订答案。

## 2. Visual Design

- 使用影像优先模板的 Modern Civic System 表现层：顶部只常驻三项数值和世界入口；状态栏以下是一张固定全画幅场景图；地点、当前行动、关键对白、结果和行动码头按回合阶段浮现在画面内。
- 场景图使用 `512×640` 的 4:5 竖幅母版意图，主体、脸、空白王印和关键证物位于中央 58% 安全列；桌面端延展环境而不放大成手机壳。
- 进入游戏后的第 0 场必须停在玩家作出第一次选择之前：书记刚拆信、路牌失名、村庄开始褪色、玛拉仍与玩家保持距离；禁止提前画出拉住玛拉、抢救登记页、冲向桥头或王印已经生效的结果。
- 每个成功回合创建一张绑定该场景的图片；生成中保留上一张完成画面，文字与本地结算不等待图片。
- 每页画面字幕最多两行；超长按句分页。角色对白显示身份牌和姓名，旁白不伪装头像。
- 画面字幕是条件元素：只有新增局面、必要后果或人物对白才显示；“请做出选择 / 接下来怎么做”和图片协议元数据不进入画面，选项足以表达动作时允许完全没有字幕卡。
- “被删除”在场景中表现为真实空间失去颜色、材质、声音与连续性，不把所有图片做成书页、拼贴或 UI 截图。
- UI 使用象牙纸、深墨边界、钴蓝行动、朱红删除签和黄铜恢复反馈；不使用通用玻璃卡、霓虹光、圆角 SaaS 面板或 Emoji 图标。
- 开场、普通探索、对话、物品发现、危险警告、对峙、失败、地点恢复和生成终局各有独立镜头意图；重大地点恢复与最终修订可生成 5 秒视频，相邻视频至少间隔 6 个回合。
- 游戏内支持中文与英文；正式海报 1024×1024，只允许英文标题和英文文本，禁止中文、伪中文和双语混排。

## 3. Game Mechanics

### 3.1 玩家身份与开场

- 玩家是未进入皇家总册的边境信使。未登记使玩家能短暂抵抗删除，也意味着官方道路、门卫和居民不一定承认玩家。
- 开场地点为苹果谷。玩家送达一封密封信，离开后回头发现村庄从路牌、道路和护送者记忆中消失，只有制图学徒玛拉仍记得它。
- 开场必须让玩家亲历 `6` 拍而不是阅读世界观摘要：信使抵达 → 书记拆信 → 路牌失名 → 车夫与房屋开始遗忘/褪色 → 握量尺的制图学徒自报玛拉并求玩家作证 → 登记页、玛拉与桥同时进入危机。前 `5` 拍隐藏选项和自由输入，第 `6` 拍才开放第一次抢救。
- 首个目标：保护玛拉、找出苹果谷被删除的原因，并在天黑前用空白王印恢复一个安全地标。
- 开场前 5 分钟只教学三条规则：被划掉的事物会消失；活人和有来源的实物可以作证；空白王印能暂时写回一个已被证实的事实。

### 3.2 世界不可变规则

1. 只有皇家总册和空白王印能改变登记事物是否存在；普通文字没有魔法。
2. 删除顺序为公共记录与道路 → 大多数人的记忆 → 物理存在；被删除的人进入“页边”，不是无提示死亡。
3. 永久恢复需要三类相容证据：活着的见证人、仍有用途且有来源的实物、可核对的真实叙述。
4. 空白王印只能临时恢复玩家亲眼见过且已有证据支持的事实，不能凭空创造人物、宝物或历史。
5. 已确认的伤势、所有权、承诺、伙伴加入/离开、地点恢复和结局选择必须持久化，AI 不能在后续旁白中改写。
6. “大修订”由主线承诺推进，不按对话次数或现实时间倒计时。

### 3.3 三项常驻数值

| 数值 | 范围与初值 | 每回合最大变化 | 直接后果 |
|---|---:|---:|---|
| 体力 | `0–100`，初始 `82` | `22` | 低于 `30` 时正面危险检定受限；到 `0` 后带伤撤回最近已命名地点，保留剧情与物品所有权。 |
| 补给 | `0–12`，初始 `7` | `3` | 旅行、扎营、治疗和照顾伙伴消耗；低于 `2` 显示警告，到 `0` 时危险检定获得 `-2` 情境修正。 |
| 被记得 | `0–100`，初始 `48` | `18` | 越高，人物、道路和官方入口越能承认玩家；低于 `25` 时部分交互关闭，到 `5` 以下会被迫在最近地标重新确认身份。 |

“被记得”是单向可读的稳定度：高是好事，低会带来风险。皇家猎手不从这根进度条暗中计算，而是追踪每次使用王印后产生的明确痕迹；危险警告会直接告诉玩家痕迹来自哪次行动。

### 3.4 空白王印与见证页

- 空白王印是不可丢弃的传奇物品，每章有 `3` 格见证墨。
- 每次使用消耗 `1` 格，可临时登记一位人物、一处地点或一条路线，持续到当前章节结束。
- 王印不能创建未经观察和证实的事实；合法使用必须引用一个人物、物品或现场事实 ID。
- 全篇有 `6` 张“见证页”：苹果谷、古林、钟市、红堡、灯塔海岸和页边各一张。每张由一名见证人、一件有来源且仍有用的物品和一段可核对的叙述组成。
- 获得任意 `4` 张见证页即可进入王都终章；收齐 `6` 张并完成至少两条伙伴和解线，可单人解锁更困难的终局。多人永久锚点不参与主线解锁。

### 3.5 地区与主线结构

1. **序章：不存在的苹果谷（10–14 个决策）**——建立三条简单规则，玛拉加入，玩家第一次写回地标并留下可被追踪的痕迹。
2. **第一幕：仍在地图上的四条路（20–32 个决策）**——古林、钟市、红堡和灯塔海岸开放；玩家任选两区完成后推进，中途可返回、改道或处理伙伴支线。
3. **幕间：归名之夜（8–12 个决策）**——已被删除的人短暂返回。玩家与玛拉第一次见到失去的人，却发现他们在页边已经度过多年；天亮前无法把所有人留下。
4. **第二幕：恢复也会伤人（18–28 个决策）**——剩余地区与冲突历史全面展开。恢复道路会叠加产权、战争记忆和家庭关系；奥伦的旧罪、塞拉的物品来源与玛拉母亲的新生活进入同一矛盾。
5. **第五章：写在页边的人（10–16 个决策）**——玩家主动进入页边寻找失踪者和自己的信使前辈伊莱，得知自己未登记并非偶然，而是别人替玩家作出的保护性选择。
6. **第六章：第二次失去苹果谷（8–12 个决策）**——王室为阻止重叠现实彻底关闭苹果谷条目。玩家只能保住人物、地点和真相中的两类，除非此前完成额外证据与关系条件。
7. **第三幕：知道你名字的猎手（8–14 个决策）**——奥伦根据全部历史选择逮捕、帮助或挑战玩家；维尔公开自己的损失与维持唯一总册的真实理由。
8. **第四幕：王都不记得国王（12–18 个决策）**——获得任意 `4` 张见证页后可以进入王都；公开申诉、地下页边、骑士通道和灯塔水路根据玩家关系开放。
9. **终章：大修订（8–12 个决策）**——最终选择不是几个固定制度按钮，而是一连串关于证据、伙伴、玩家名字、页边通道和维尔命运的决定。系统先计算玩家真正拥有的终局能力与必须承担的代价，再由 AI 在结局语法内组合出独特结局及人物化尾声。

#### 3.5.1 第一段开放章节：古林

- 苹果谷章节节点之后，玩家可进入古林；玛拉、背包、伤势、王印痕迹、奥伦已经核验过苹果谷等状态必须原样延续，不能因换区重置或被新人物替换。
- 古林主线包含 `7–10` 个有效决策，依次完成：发现道路循环、认识本地守路人托玛、选择一种寻路方法、取得有来源的“双向里程钉”、经历一次 `warning → confrontation → resolution` 危险、决定古林保留哪一种道路秩序、取得古林见证页并进入可继续的章节节点。
- 三条寻路方法必须产生不同世界事实：沿动物迁徙判断仍被使用的路线、恢复皇家直线路标、让分隔两地的居民从两端相向而行。三条路线都能推进，不设置唯一正确解。
- 双向里程钉必须真实进入背包，包含数量、稀有度、能力、限制、来源、两项指标和物品生图提示；它只能在两端都有活人记忆、且已核对旧路交点时稳定道路，不能凭空制造新路。
- 本章危险是会把岔路折回原处的“折路兽”与循王印追来的皇家测路猎手。玩家始终可选择正面保护、利用地形与测量规则、或依靠玛拉和托玛协作；失败造成体力、补给、追捕或路线代价，不删除物品、伙伴或存档。
- 地区结算提供三种可承担结果：恢复皇家直路（最快但压过支路）、建立居民共同维护的多路图（最慢但证词分散）、只锚定过河点并保留动物迁徙带（生态完整但通行困难）。三种结果都写入稳定事实，并改变以后古林的路线、补给、追捕和尾声。
- 完成本章后写入 `oldwood-witness-page=true`、`witness-pages=1` 与一个古林结算事实；这是可继续的章节节点，不是真结局。下一步仍可去钟市、红堡、灯塔海岸，或返回古林处理支线。

#### 3.5.2 完整战役与 AI 导演边界

- 产品提供一条 `31` 个关键行动的中英文压缩战役，用于离线试玩与全流程回归：苹果谷 → 古林 → 钟市 → 红堡 → 灯塔海岸 → 归名之夜 → 页边 → 第二次失去苹果谷 → 白石王都 → 总册高塔 → 大修订。它覆盖全部八个章节合同、六张见证页、三名稳定伙伴、四件关键物品与终局启动，不以“试玩切片”结束。
- 正式 Aigram 模式不照抄这 31 步，也不受固定回合数限制。`StoryDirector` 向 AI 提供八章的解锁条件、情绪目的、必经节拍与完成事实；AI 可在章节内生成支线、人物、危险和自由行动结果，但不能跳章、重启主线、提前写入完成事实或把支线替换成主线。
- 见证页数量由本地根据 `*-witness-page` 稳定事实推导；AI 不能直接声明 `witness-pages=4/6` 来解锁王都。终章必须同时满足真实见证页、总册入口与玩家明确作出的不可逆行动。

### 3.6 固定人物与知识边界

- **玛拉 / Mara，`mara-cartographer`**：苹果谷制图学徒，第一位稳定伙伴；只知道亲眼画过的地点和家人线索，不会自动知道王都秘密。
- **奥伦 / Oren，`oren-knight`**：皇家骑士与阶段性追捕者；相信统一记录能阻止战争，只有在亲眼看见总册伤害无辜后才可能转变。
- **塞拉 / Sera，`sera-peddler`**：贩卖被删物品的旧货商；熟悉物品来源和黑市路线，但不免费提供帮助，也不能凭空鉴定未知宝物。
- **伊莱 / Eli，`eli-courier`**：把玩家带入信使行当的前辈，曾替玩家隐去登记以保护玩家；只通过旧信、物品和页边相遇逐步出现，不能提前替玩家解释全部身世。
- **维尔 / Veyr，`veyr-regent`**：摄政官与主要对手；知道旧灾难和总册机制，但不知道玩家在未公开地区取得的证据。
- AI 可创建本地人物，但不得替换上述 ID、静默移除伙伴、制造第二位摄政官或让角色引用其知识范围外的事实。

### 3.7 自由探索、支线与线程控制

- 玩家可拒绝所有建议，输入任意合法行动；AI 根据当前位置、连接道路、已知事实、伙伴和物品响应。
- 核心循环保持可见且简单：`进入地点 → 遇见一个具体问题 → 通过行动/调查/关系取得证据或资源 → 决定恢复、保留还是离开 → 打开下一条路`。共享痕迹只插在需要时帮助其中一步。
- 同时最多保留 `3` 条活跃线程：一个当前主目标、一个人物/地区支线、一个危险或多人痕迹。新线程出现前必须完成、暂停或明确放弃旧线程。
- 每个回合至少改变地点、证据、人物状态、关系、物品、路线、危险阶段、数值或已确认世界事实中的一项。
- AI 可以生成本地居民、天气、小型遗迹、工作、传闻和普通宝物；不能生成第二枚王印、改写国王死亡、提前宣布主线地点永久恢复或直接给出终章答案。

### 3.8 危险、战斗与失败

- 普通探索持续 `2–4` 个安全回合后，危险导演才进入 `warning → confrontation → resolution`；结算后至少冷却 `2` 回合。
- 物理战斗允许，但每次对峙必须同时提供三种策略：正面保护/战斗、观察规则/寻找路线、交涉伙伴/消耗资源。
- 五级危险 DC 为 `7 / 10 / 13 / 16 / 19`；本地固定 d20 由游戏、场景、遭遇周期和行动计算，刷新与重试不重掷。
- AI 必须叙述本地检定结果；若失败或代价成功没有合法后果，本地默认扣除体力 `14`，并记录来源事件。
- 失败可以造成伤势、补给损失、见证墨消耗、“被记得”下降、伙伴被拘押或道路关闭；不能删除存档、凭空删除背包、重置伙伴关系或让故事只剩“继续”。

### 3.9 异步共享世界

- 多人层仅在权威远端世界可用；没有远端服务时显示单人世界，不把 localStorage 模拟称为多人。
- 每区最多显示最近 `6` 条有效页边批注，同一作者最多 `2` 条；批注包括见证、警告、路线、物资和修复。
- TTL：见证 `48h`、警告 `72h`、物资 `96h`、路线 `168h`、修复 `168h`。到期依据服务器时间退出正常显示。
- 每个主场景最多自动呈现 `1` 条与当前位置相关的玩家痕迹；完整六条进入世界抽屉，不能淹没主线对白和选择。
- 公共物资封包有 `3` 份，原子领取后生成回执；物品先进入个人 Aigram 存档并回读确认，再向世界服务 ack。封包作为真实背包物品，使用后补给 `+2`，不能直接由共享服务改写私人数值。
- 每个区域有一个 `7` 天公共修复工程；每位玩家每工程贡献一次固定 `25`。达到 `100` 且至少 `3` 位不同玩家后，服务器结算为永久地标候选。
- 永久锚点改变支线道路、补给、背景画面和尾声名单，不提供唯一见证页、不替代主线伙伴，也不锁定任何结局。
- 所有共享写入带 `action_id` 与 `expected_version`；版本冲突刷新后最多重试 `3` 次。公共内容支持举报，三名不同用户举报后从普通查询隐藏。

### 3.10 影像与里程碑

- 每个成功回合恰好一张场景图；prompt 从当前行动、地点、出场人物和已确认后果重新构建，不继承开场村庄或海报构图。
- 玩家执行镜头主要动作时，直接使用平台原始 1:1 头像 URL 作为身份参考，最终场景尺寸由媒体服务独立输出为 `512×640`；“信使 / courier”只用于判断玩家是否出镜，进入 renderer 前统一改写成 `SUBJECT A`，不能强制出中世纪人类。玩家只是陪衬、玛拉或其他角色主导、环境空镜和物品特写时不使用玩家头像。玩家参考拥有完整外形而不只是脸；不得与玛拉、奥伦、托玛、马、鹿或猎兽交换或混合，也不得补出原头像不存在的脸、皮肤和手脚。
- 首次进入时，玩家主导的第一张图必须等待平台头像解析。外部宿主注入窗口为 `10.5s`，已经确认处于平台但资料接口暂时失败时继续重试到 `30.5s`；等待期间显示世界观占位和显影反馈。存档中身份版本低于 2 的前两张玩家图，在头像到达后自动重做一次并永久标记完成。
- 传给生图模型的场景提示必须全英文；故事正文、地点中文名和协议原文不得拼入渲染提示。路牌、书、地图、信件、印章和纸面只能留白或使用非语言抽象标记，禁止中文、拉丁字母、数字和伪文字。
- 物品图在玩家首次打开背包后后台排队，遵循同一高幻想材质；对象图不使用头像参考。
- 地点永久恢复、奥伦阵营转折、王都总册开启和三个终局为视频候选；视频默认 `5s`，生成失败保留静态图。

### 3.11 领域规则裁判与首次登场

- 模型只叙述被王印与世界规则裁定后的结果；本地 `domainRules` 决定开场三选一、苹果谷首个写回地标、精确数值、背包和后续三选项。命中规则的整回合丢弃全部模型协议命令。
- 开场只能提交一个 `first-rescue`：`mara`、`registry-page` 或 `bridge`。救玛拉固定被记得 `+6`；救登记页固定得到唯一 `apple-registry-fragment`；冲桥固定体力 `-5` 并记录桥长证据。提交后不能再领取另一路收益。
- 苹果谷只能提交一个 `apple-anchor`：桥梁固定补给 `-1`，面包房固定补给 `+3`，钟楼固定被记得 `+8`；第二次尝试只解释旧承诺并提供仍可行的行动，不改数值、不改事实、不推进危险。
- 玛拉在开场正文中已可见并自报身份，因此属于初始已知人物；奥伦、塞拉、伊莱和维尔在各自可见登场前不得出现在人物面板、队伍、关系、目标或选项中。首次登场依次说明可辨认外形/动作、名字来源、当前关系/意图，然后才以稳定 ID 写入存档。

## 4. Controls

- 第 `0` 场开场使用单向字幕推进：每次点击至少 `44×44 CSS px` 的前进控件只揭示下一拍；最后一拍后分页控件消失，三个抢救行动和自由输入同步出现。数字键 `1–3` 在此之前无效。
- Touch/Pointer：行动按钮完整点击一次立即提交；结果回来后点击一次“查看下一步选择”进入下一决策，二者不同时出现。
- 每轮的结果叙事与下一轮决策前提必须按先后展示：结果阶段隐藏常驻画面字幕，把按时间顺序出现的第一段主要叙事放入自适应结果薄层；玩家点击“查看下一步选择”后，结果薄层收起，画面字幕再显示 `[choices]` 前最后一段旁白、对白或作者事件，并同时出现对应选项。禁止继续把上一行动的第一段结果当作下一组选项的“此刻”。
- 场景图提供地点、人物、危险与空间关系的视觉判断，但所有会改变状态的选择仍保留简短文字标签；图片不能独自承担物品归属、关系承诺、路线代价或三项相似行动之间的精确区别。
- 可滚动的页边批注、世界实体、背包、地图和人物列表使用 `onClick`，手指滑动不误触。
- 自由行动先打开独立输入区，再由发送按钮或 Enter 提交；普通行动不需要二次确认。
- Keyboard：数字键 `1–4` 选择行动；`W` 打开世界；`H` 打开分镜历史；`Escape` 关闭最上层面板。
- 世界抽屉提供人物、地图、背包、日志与共享页边入口；物品、地点、人物和永久锚点均可点开查看作用、限制、来源和当前状态。
- 所有触控目标至少 `44×44 CSS px`；支持 `320×568`、`390×844`、`1024×768`、`1440×900`，移动端不依赖 hover。

## 5. Win / Lose Conditions

- 获得任意 `4/6` 张见证页后可以进入终章，但玩家可在最终启动大修订前继续探索遗漏地区和伙伴支线。
- 结局不是固定列表。系统根据 `6` 张见证页、三条伙伴关系、伊莱书信、玩家是否恢复自己的登记、页边通道、维尔处置和地区冲突，生成一份不可伪造的“终局能力清单”；AI 只能组合清单中真实存在的动作与代价。
- 人工提供 `8` 个锚点结局作为质量下限和测试样本：**唯一黎明、无册之路、众人图册、页边守望者、万名之冠、双重黎明、仁慈大修订、最后一封信**。AI 可以生成锚点之间的混合结局、由自由行动推导的新结局名称和新的情绪落点，实际结局数量不封顶。
- 每个生成结局必须包含：一个被保住的核心事物、一个不可撤销的代价、一段私人关系的告别或重逢、至少三个地区/人物尾声、一个仍未解决的未来问题；不能生成没有代价的完美胜利。
- “众人图册”和“双重黎明”类能力要求 `6/6` 见证页及至少 `2` 条伙伴和解；“守住页边”类能力要求完整页边见证与玩家仍未登记；其他能力由终章前真实完成的行动产生。
- 生成后保存结构化结局快照与完整文本；同一份终章存档刷新、重进或离线恢复都显示同一个结局，不允许靠刷新重抽。玩家若从终章前锚点作出新行动，才会产生新的结局。
- 若 AI 生成内容引用不存在的人物、复活已确认死亡者、遗漏仍在队伍中的伙伴、改写物品所有权或创造新魔法规则，系统拒绝该版本并要求基于同一终局能力清单修复；多次失败则回退到最接近的锚点结局。
- 多人永久锚点只改变尾声中恢复的支线地点、公共道路和署名，不解锁任何一个主要结局。
- 体力到 `0`、补给到 `0` 或“被记得”低于 `5` 都不是删除存档的死亡：玩家在最近已命名地点恢复，带着伤痕、时间/路线变化和已发生的人物后果继续。
- 不可逆终局失败只在玩家明确接受总册抹除自己、且经过二次确认时发生；结算仍保留完整记录与“重新开始”。
- 结局界面显示：生成结局标题、最终地图、六张见证页状态、伙伴去向、传奇物品、三项数值、多人永久锚点贡献、关键选择摘要、最后图片/视频、“继续尾声”和“重新开始”。

## 6. Sound Effects

- 使用参数化 Web Audio，不依赖外部音频文件；首次玩家手势后解锁，后台暂停，失败不阻塞剧情。
- 声音身份采用“**被删除的三音动机 / 被写回的开放五度**”：删除事件把 `12 → 6 → 0` 半音动机向下折断；王印、见证页与地点恢复把 `0 → 7 → 12` 动机重新展开。两个动机贯穿环境、反馈与终章，但同一反馈不连续播放超过 `2` 次。
- 基础速度 `58 BPM`、基频 D3 `146.83 Hz`；音乐不再使用模板统一八拍循环，而由当前位置选择稀疏动机和材质。音乐 `0.12`、环境 `0.13`、反馈 `0.44`、总线 `0.48`，给对白和阅读保留空间。
- 七类地区声景必须可辨：苹果谷为木管式正弦与果园空气；古林为低木质脉冲与不规则枝响；钟市为克制黄铜/钟片；红堡为低频行军间隔与不协和二度；灯塔海岸为潮噪与玻璃高音；页边为长静默和倒置残响；白石王都/总册高塔为冷硬钟摆与登记节拍。进入新地区后 `160–300 ms` 交叉切换，不重建页面或中断操作。
- 普通行动：`70–110 ms` 纸张/木质短音，`180–280 Hz`；同帧给出按下反馈。自由输入使用同一确认，不制造更高等级奖励声。
- 王印使用：`420–620 ms` 的 `0 → 7 → 12` 三音加 `90 ms` 干燥印章噪声；地点恢复再叠加低频回归，强度 4。生成图片或视频就绪只使用轻微 `180–260 ms` 显影声，不能盖过恢复本身。
- 删除/“被记得”下降：`240–360 ms` 的 `12 → 6 → 0` 下行动机与窄带擦除噪声；若同回合已有失败声，只播放删除尾音，避免重复惩罚。
- 危险警告：最多 `2` 个 `73–82 Hz` 脉冲，间隔 `180 ms`；进入对峙追加一次短促不协和音，结算失败使用 `260 ms` 低音和 `90 ms` 干脆断音。
- 伙伴加入/和解使用 `320–420 ms` 双声部靠拢；普通物品使用 `180–260 ms` 木质双音；见证页使用独立的 `0 → 5 → 7 → 12` 四音并保留最后一个音 `520 ms`，让玩家不用看颜色也能辨认里程碑。
- 终章不换成通用胜利号角：根据已获得见证页数量逐步补齐被写回动机，最终结局使用 `900–1300 ms` 的开放和弦；仍有重大代价时保留一个未解决的二度音。
- 静音偏好本地保存，不写入 StorySave；`prefers-reduced-motion` 不改变声音语义，但静音时所有视觉反馈仍完整。
