# 《被删去的王国》领域规则实验记录

## 假设

高幻想世界即使规则写得完整，只要模型同时负责解释规则和修改权威状态，仍会出现开场三选一被重复领取、王印同时写回多个地标、数值膨胀或未来人物提前入队。把这些承诺交给本地领域裁判，可以保留开放叙事而消除事务漂移。

## 实验

- 开场三项抢救共享 `first-rescue=unset` 门槛，只能提交一个结果。
- 桥梁、面包房和钟楼共享 `apple-anchor=unset` 门槛，只能写回一处，并分别结算补给 `-1 / +3` 或被记得 `+8`。
- 对抗模型在同一回合尝试补给 `+12`、被记得 `+40`、重写两个承诺、提前让维尔入队并返回无关选项。
- 连续游玩选择登记残页 → 写回桥梁 → 再试面包房；角色测试覆盖未来角色旧存档预载和奥伦的合法首次登场。

## 结果

机械测试最终保持 `first-rescue=registry-page`、唯一登记残页 `1`、`apple-anchor=bridge`、补给 `6`、被记得 `48`，越权的维尔未出现。390×844 浏览器流程可见登记残页进入信使包、桥梁补给 `-1`，第二地标被明确拒绝。

## 结论

世界观规则仍适合写在 cartridge 与 prompt，帮助模型理解“为什么”；但一旦行为涉及互斥承诺、精确资源、唯一物品、队伍或解锁，必须由代码回答“能不能”和“改什么”。两层并用时，叙事自由度没有被削掉，状态可靠性却从概率约束变为可回归验证的事务合同。
