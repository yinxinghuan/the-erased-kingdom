# 《被删去的王国》界面简报

## 玩家与场景

- 玩家：希望自由探索、愿意建立伙伴关系，但不想先阅读复杂设定的移动端 RPG 玩家。
- 典型单次会话：8–15 分钟；存档可跨会话继续。
- 首要目标：看懂当前发生的一件事，并用一次点击采取行动。
- 情绪承诺：先让玩家喜欢一个具体的人和地方，再让其选择愿意为谁承担不可撤销的代价。

## 核心交互

- 主交互：在固定 4:5 场景图上阅读一条关键情境，点击一个具体行动立即提交。
- 次交互：查看人物、地图、背包、日志和异步痕迹；自由行动单独打开输入。
- 主画面始终只回答一个问题：现在发生了什么，以及玩家下一步能做什么。

## 平台与输入

- 主平台：AlterU 移动端 WebView，竖屏优先。
- 同时支持外部桌面浏览器；桌面扩展成叙事墙，不套手机壳。
- 目标尺寸：320×568、390×844、768×1024、1440×900。
- 输入：Touch、Pointer、Keyboard；滚动列表项用 Click，立即行动用 Pointer/Click 去重后的单次提交。
- 中文、英文双语；正式海报只使用英文。

## 层级

1. 场景图与当前人物/危险。
2. 一条关键情境或对白。
3. 当前可执行行动。
4. 本轮检定、物品与数值变化。
5. 世界资料、历史和多人痕迹。

## 已选参考与明确拒绝

- 采用 Modern Civic System 的硬线网格、全画幅叙事墙和主题色行动码头。
- 拒绝聊天长流、所有信息同时罗列、固定高度空白结果卡、横向等宽巨按钮、封面构图重复进入运行时图片。

## 必需资产与状态

- 512×640 苹果谷开场图和逐回合场景图。
- 玩家头像 512×640 裁切参考、四名主要角色稳定描述、物品方图。
- 开场、决策、提交中、结果、长文分页、危险、恢复里程碑、背包、世界、断网、生成失败、继续/重开和生成式结局。
