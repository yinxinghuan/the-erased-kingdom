# 《被删去的王国》屏幕与状态合同

## 1. 封面 / 未进入

- 玩家问题：这是什么世界，我为什么要开始？
- 主焦点：苹果谷正在消失的叙事场景。
- 主操作：进入旅程。
- 次操作：语言、声音、文字大小。
- 禁止：自动滚到底部、先出现多人痕迹、用海报代替场景背景。

## 2. 返回存档

- 显示结局前最近地点、当前目标和短摘要。
- 主操作：继续游戏并跳到最新有效锚点。
- 次操作：确认后重新开始。
- 选择后弹窗消失，不在主界面保留重复按钮。

## 3. 决策

- 玩家问题：此刻发生什么，我能怎么做？
- 主焦点：场景图中下部的关键情境铭牌。
- 主操作：底部 2–4 个具体行动；移动端单行横向滚动、自适应宽度。
- 次操作：自由行动入口。
- 常驻：三项数值与世界入口。
- 隐藏：上一回合结果、上一行动条、无关多人信息。

## 4. 提交中

- 同帧收起行动；右上蓝条显示已提交行动。
- 保留上一张完成图片，窄进度条显示世界回应；不全屏加载。
- 防止重复提交；失败时保留行动与就近重试。

## 5. 行动结果

- 新场景图完成前先显示本地检定和文本结果；图片到达后淡入。
- 关键结果或对白显示于画面铭牌；补充因果、数值和物品进入自适应薄层。
- 薄层 52–138 px，超过上限才内部滚动；无补充内容时隐藏。
- 底部只有“查看下一步选择”，不同时显示新选项。

## 6. 危险

- Warning：朱红地点签旁出现可读警告和来源，不遮住主情境。
- Confrontation：三个行动必须覆盖正面对抗、观察规则/路线、伙伴/王印代价。
- Resolution：固定检定、伤势和物品变化先落库，再生成叙述与画面；刷新不重掷。

## 7. 世界页

- 全屏纸张档案，入口互通：人物、地图、背包、日志、页边批注、公共工程。
- 人物页显示状态、关系来源、伤势、技能与最后地点。
- 背包从真实持久化物品读取；首次打开后后台排队生成物品图。
- 多人页最多六条有效痕迹；头像与名字成对显示并可打开资料。

## 8. 生成式终局

- 生成前：展示玩家真实拥有的终局能力与每项不可撤销代价，不提前显示固定结局按钮。
- 生成中：回放 3–5 个关键选择作为视觉进度，不显示随机抽取暗示。
- 完成：标题、结局命题、4–6 个场景、保住/失去/未解决、每位主角去向、至少三个地区尾声、最终图或视频。
- 操作：继续尾声、从终章前锚点改写选择、确认后重新开始。
- 同一终局快照刷新后显示相同结局。

## 9. 错误与降级

- AI 回合失败：保留选择与行动，提供重试或切换可用接口。
- 图片失败：剧情继续，画面原位重试。
- 结局违反事实：自动修复两次；仍失败则使用最接近锚点结局。
- 多人后端不可用：隐藏写入操作并显示单人世界，不用本地假数据冒充共享世界。
