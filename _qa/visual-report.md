# 《被删去的王国》Civic 完整战役视觉 QA

## 验收范围

- 平台内布局：320×568、390×844、1024×768、1440×900。
- 状态：入口、开场决策、行动结果、下一决策、分镜历史、钟市、页边、终章门槛与结局长页。
- 外部分享访问：登录层与关闭后的英文入口。
- 交互断言：结果阶段不显示下一组选项；下一步按钮后才进入决策；可选与禁用按钮边界不同；结果薄层高度低于 360 px；无横向页面溢出。

## 第一轮发现与修复

### P1 · 开场第一眼缺少核心情境

- 位置：开场决策，390×844 与 320×568。
- 观察：Civic 为减少信息堆叠而优先显示玛拉对白，完整背景留在历史中；原台词只说“别转身”，单看画面文字不能立即确认村庄正在消失。
- 影响：玩家可能先理解成人物请求，而不是“保护证人、阻止村庄被删”的紧急目标。
- 修复：把“村子正在消失”写入玛拉首句，不增加第二张面板。
- 复验：`cinematic-civic-opening-platform-layout-390x844.png` 与 `320x568.png` 的主对白已直接说明消失事件。

### P2 · QA 在样式过渡中误判禁用边界

- 位置：可选按钮状态断言。
- 观察：测试在同一渲染帧写入 `disabled` 后立刻读取样式，读取到主题色过渡起点。
- 影响：不影响玩家，但会造成错误发布拦截。
- 修复：QA harness 等待两个动画帧再读取；可选按钮保留钴蓝边界与硬阴影，禁用最终态为灰色且无阴影。

## 第二轮发现与修复

### P1 · 分页文本仍被两行截断

- 位置：奥伦对白与行动结果，390×844。
- 观察：文本虽已分成两页，单页仍被 `line-clamp: 2` 裁掉，因此最后一页也可能出现省略号。
- 修复：角色对白按 44 个宽度单位、旁白按 54 个宽度单位分页，并移除 Civic 字幕的二次行数截断；结果补充内容使用独立分页组件，容器上限提高到 `min(26dvh, 196px)`。
- 复验：奥伦对白现在拆为三页，浏览器测得三页 `clientHeight === scrollHeight`，且 `overflow: visible`、无 `line-clamp`。

### P1 · 同回合事实通知重复

- 位置：面包房恢复结果。
- 观察：两个 `[fact]` 命令分别生成相同的“一项事实已被世界记住”。
- 修复：存档仍逐项写入事实，但反馈合并为一次“世界记录已更新 · N 项事实”；协议测试增加两项事实只产生一个通知的断言。

### P2 · 顶部四个入口不统一

- 位置：主 HUD 顶部。
- 修复：历史、字号、声音和世界统一为 44×44 四格工具栏；字号改用同族 SVG 图标，世界不再混入文字宽按钮；激活态使用主题蓝/绿。

### P2 · 竖幅画面视觉重心偏下

- 位置：Civic 主舞台。
- 修复：第一轮 52 / 46 px 改善不足后，画面进一步向上延伸至常规屏 88 px、短屏 72 px，由不透明仪表盘遮挡上部画面；所有地点、行动和生成状态标签向下补偿同等距离。
- 复验：390×844 和 320×568 平台布局中仪表盘完整，画面从其后方连续延展，交互标签均在仪表盘下缘可见。

## 完整战役回归

- 浏览器从首页实际点击 `31` 个关键行动抵达大修订；不是向 localStorage 直接注入终章。
- 每个成功回合都生成一个独立场景图块：开场 `1` 张 + 行动 `31` 张，共 `32` 个图块；图片网络生成不阻塞状态结算。
- 六张见证页由地区事实推导，玛拉、塞拉与奥伦三名伙伴保持稳定，关键背包物品不因跨章丢失。
- 终章门槛、AI 失败时的可靠锚点结局、继续尾声均能从真实界面进入；结局长页允许纵向阅读，不用截断正文换取首屏塞满。
- `cinematic-civic-campaign-bell-market-platform-layout-390x844.png`、`cinematic-civic-campaign-margins-platform-layout-390x844.png`、`cinematic-civic-finale-gate-platform-layout-390x844.png` 与 `cinematic-civic-ending-platform-layout-390x844.png` 为完整路线证据。测试以透明像素替代远端图片，只验排版与状态流；真实画面质量沿用前轮实图证据并需在正式模型上线后持续抽样。

## 第三轮：开场图文时序一致性

### P1 · 第 0 场静态图提前演出了玩家选择

- 位置：首次从封面进入苹果谷，场景图尚在生成时。
- 观察：旧入口图已经画出玩家抓住玛拉的手，属于“拉住正在褪色的玛拉”的行动结果；但玩家此时尚未在玛拉、登记页和桥头之间作出选择。与此同时，Civic 首要字幕默认取开场最后一个事件，只显示书记桌上的登记页，和画面中的村道危机也不是同一镜头。
- 影响：第一张图提前替玩家做决定，图片、字幕、三个按钮分别处于三个时间点，破坏第一印象和选择可信度。
- 修复：平台 transit img2img 重做 4:5 开场等待图；信使和玛拉保持距离，空路牌、褪色房屋、困惑车夫与书记门口共同表示“危机刚发生”，明确禁止握手、拉拽、救援、王印生效、已恢复地标、战斗和骑士。旧图保存在 `_production/rejected/the-erased-kingdom-entry-choice-result.webp`。运行时 `image-0` 同步采用新 prompt，并写入 `playerVisible=true`，保证正式生成时使用玩家头像参考。
- 字幕修复：为开场第一段增加明确 `stageOverlay`，首屏先显示“送信、拆信、路牌失名”，不再跳到第三段书记桌面细节；三个选项仍在叙事建立后出现。
- 复验：`cinematic-civic-opening-coherence-platform-layout-390x844.png` 与 `320x568.png`。两种尺寸均同时看见分立的信使/玛拉、空路牌、白化房屋和困惑车夫；首字幕从送信与拆信开始，三个行动仍未发生。浏览器断言同时确认 prompt 包含选择前时序约束、`playerVisible=true`，头像测试确认开场与首个行动分别携带玩家参考。

## 第四轮：连续人物身份与画面文字

- 发现：部分包含信使的镜头被 AI 标为 `environment / others`，本地曾把该标签当作绝对结论，因此首图使用头像参考，后续同一主角镜头却退化为模型生成的通用信使；中文故事正文直接拼入渲染提示也提高了纸面和招牌生成汉字的概率。
- 修复：本地导演加入玩家职业别名复核，语义证据优先于错误的 subject 标签；每个玩家镜头复用同一裁切头像并追加唯一主角身份硬约束。渲染提示改为全英文，含 CJK 的 AI 图片提议拒绝使用，所有可承载文字的表面要求留白或非语言标记。
- 自动复验：浏览器连续推进三张玩家镜头，三次请求均使用同一 `ref_url`、均包含身份硬约束且均无 CJK；image-director 单测覆盖错误 subject 标签和中文提议兜底。
- 真实模型复验：同一虚构参考人物分别生成面包房和桥上战斗场景，人工确认脸型、短卷发、绿眼和右脸伤痕连续，两张均无可读文字。来源 URL 记录于 `doc/image-provenance.md`。
